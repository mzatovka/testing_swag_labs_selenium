# Testing Swag Labs Selenium

Автоматизированное UI-тестирование интернет-магазина **Swag Labs** с использованием Python и Selenium WebDriver.

Проект содержит автоматизированные тесты для проверки авторизации пользователя, работы с товарами и добавления товара в корзину.

## 🛠 Использованный стек

* **Python** — язык программирования.
* **Selenium WebDriver** — автоматизация взаимодействия с веб-браузером.
* **Chrome WebDriver** — запуск тестов в браузере Google Chrome.
* **unittest** — стандартный фреймворк Python для написания и запуска тестов.
* **selenium.webdriver.common.by (By)** — поиск элементов страницы по ID, CSS-селекторам и другим локаторам.
* **Keys** — эмуляция нажатия клавиши `ENTER`.
* **time** — использование задержек между действиями.
* **requirements.txt** — файл с зависимостью проекта `selenium`.

##  Тестируемое приложение

В проекте тестируется интернет-магазин:

**Swag Labs / Sauce Demo**

https://www.saucedemo.com/

##  Использованные тест-кейсы

### 1. Авторизация с корректными данными

**Тест:** `test_username`

Проверяется успешная авторизация пользователя.

**Шаги:**

1. Открыть страницу Swag Labs.
2. Ввести логин `standard_user`.
3. Ввести пароль `secret_sauce`.
4. Нажать кнопку Login.
5. Проверить URL после авторизации.

**Ожидаемый результат:**

После успешной авторизации пользователь переходит на страницу:

`https://www.saucedemo.com/inventory.html`

---

### 2. Авторизация с неверным паролем

**Тест:** `test_login_invalid_password`

Проверяется обработка некорректного пароля.

**Шаги:**

1. Открыть страницу авторизации.
2. Ввести логин `standard_user`.
3. Ввести неправильный пароль `wrong_password`.
4. Нажать Login.
5. Проверить текущий URL.
6. Проверить наличие сообщения об ошибке.
7. Проверить текст сообщения.

**Ожидаемый результат:**

Пользователь остается на странице авторизации и получает сообщение:

`Epic sadface: Username and password do not match any user in this service`

---

### 3. Авторизация с помощью клавиши Enter

**Тест:** `test_login_with_enter`

Проверяется возможность выполнить авторизацию нажатием клавиши `Enter` после ввода пароля.

**Шаги:**

1. Открыть страницу авторизации.
2. Ввести логин `standard_user`.
3. Ввести пароль `secret_sauce`.
4. Нажать `Enter`.
5. Проверить URL страницы.

**Ожидаемый результат:**

Пользователь успешно авторизуется и переходит на страницу товаров:

`https://www.saucedemo.com/inventory.html`

Дополнительно проверяется наличие товара на странице.

---

### 4. Проверка отображения товаров

**Тест:** `test_all_products`

Проверяется наличие товаров на странице после авторизации.

**Шаги:**

1. Открыть Swag Labs.
2. Выполнить авторизацию с корректными данными.
3. Найти элементы товаров на странице.
4. Проверить, что товары найдены.
5. Проверить отображение первого найденного товара.
6. Получить названия найденных товаров.

**Ожидаемый результат:**

На странице отображается как минимум один товар.

---

### 5. Добавление товара в корзину

**Тест:** `test_add_to_cart`

Проверяется возможность добавить товар в корзину.

**Шаги:**

1. Авторизоваться в приложении.
2. Найти кнопку добавления товара `Sauce Labs Backpack` в корзину.
3. Нажать кнопку добавления.
4. Найти корзину.
5. Проверить содержимое элемента корзины.

**Ожидаемый результат:**

Товар успешно добавляется в корзину, а корзина становится доступной для дальнейшей проверки.

##  Организация тестов

В проекте используются два тестовых класса:

* `Test_autorization` — тесты авторизации;
* `TestProducts` — тесты работы с товарами.

Для подготовки браузера используется метод `setUp()`:

* создается экземпляр Chrome WebDriver;
* открывается сайт Swag Labs.

Для завершения работы используется `tearDown()`:

* браузер закрывается с помощью `driver.quit()`.

##  Используемые локаторы

В тестах применяются следующие способы поиска элементов Selenium:

* `By.ID`
* `By.CSS_SELECTOR`
* `By.CLASS_NAME`

Также для выполнения действий с клавиатурой используется:

* `Keys.ENTER`

##  Запуск тестов

Установить зависимость:

```bash
pip install -r requarements.txt
```

Запустить тестовый файл:

```bash
python -m unittest test_internet_shop
```

Также тесты используют стандартный механизм `unittest`:

```python
if __name__ == "__main__":
    unittest.main()
```
